## О проекте

Данный репозиторий содержит исходный код и сетевую архитектуру для мультиплеерного игрового проекта, разработанного на Unreal Engine 5. 
Проект представляет собой сетевой фундамент (multiplayer foundation), на котором будет строиться основной геймплей.

## Реализованные возможности

На данный момент в проекте успешно реализованы и протестированы следующие системы:

* Система Лобби (Lobby System):
  * Создание, поиск.
  * Корректное подключение и отключение клиентов (Seamless Travel / Client Travel).
  * Обработка ошибок подключения и таймаутов.
* Интеграция со Steam (Steam Online Subsystem):
  * Настройка `OnlineSubsystemSteam`.
  * Авторизация пользователей и получение Steam ID.
  * Поддержка Steam Invites (приглашения через friends list).
* Клиент-Серверная репликация движения:
  * Настройка авторитета сервера (Server Authority) над персонажами.
  * Репликация позиций, ротаций и анимаций (Animation Replication).
  * Оптимизация сетевого трафика (Net Priority, Net Update Frequency).

## Сетевая архитектура и технические решения

### Обоснование выбора Listen Server
Для данного проекта была выбрана топология Listen Server (выделенный сервер запущен на машине одного из игроков — Хоста), а не классический Dedicated Server или чистый Peer-to-Peer (P2P). Это решение продиктовано следующими факторами:

1. Оптимизация бюджета: Проект находится на стадии активного прототипирования и имеет минимальный бюджет. Аренда выделенных серверов (Dedicated Servers) или использование облачных решений (PlayFab, AWS GameLift) потребует значительных ежемесячных вливаний, которые нецелесообразны на текущем этапе.
2. Масштабируемость и сложность P2P: Игра предполагает большое количество одновременных игроков в одной сессии. Реализация классического P2P (где каждый клиент соединен с каждым - mesh topology) в таких условиях приведет к экспоненциальному росту сетевого трафика, жестким требованиям к каналу связи хоста и критическим проблемам с десинхронизацией.
3. Баланс между стоимостью и стабильностью: Listen Server в связке со Steam Networking Sockets (Steam Relay) является "золотой серединой". Он позволяет избежать затрат на аренду серверов, при этом перекладывая проблему проброса портов и NAT на инфраструктуру Steam, что гарантирует стабильное соединение для всех участников лобби.
